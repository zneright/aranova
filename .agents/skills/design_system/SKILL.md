# UI/UX Pro Max Design System

Whenever the user asks you to build a new frontend component, you MUST always use the design system from [https://github.com/nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill).

## Instructions

1. **Review Guidelines:** If you are unfamiliar with the specific components, styles, or patterns in that design system, you must review its documentation before proceeding.
2. **Consistent Styling:** Ensure that all components you create or modify strictly adhere to the visual aesthetics, layout rules, typography, and color schemes defined in the design system.
3. **Component Reusability:** Favor reusing existing patterns and structures recommended by the design system over building from scratch.
4. **Modern UI/UX:** Prioritize a highly polished, premium, and responsive user experience as prescribed by the repository.
